# TG WS Proxy для Android

Локальный MTProto-прокси для Telegram на Android. Запускается одной кнопкой, работает в фоне и открывает Telegram со ссылкой для подключения. Приложение разработано **by skwix** на основе ядра [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy).

**[Скачать APK 0.2.0](https://github.com/skwix-hack/TgWsProxyAndroid/releases/download/v0.2.0/TgWsProxyAndroid-0.2.0.apk)** · [Релизы](https://github.com/skwix-hack/TgWsProxyAndroid/releases) · Android 8.0+ · ARM64 · 31,5 МБ

## Быстрый старт

1. Скачайте и установите APK. Если Android попросит разрешить установку из источника, из которого вы открыли файл, подтвердите разрешение.
2. В TG WS Proxy нажмите **«Запустить прокси»**.
3. Нажмите **«Открыть Telegram»** и подтвердите добавление MTProto-прокси.
4. Чтобы остановить прокси, воспользуйтесь кнопкой в приложении или уведомлении. Чтобы Telegram снова подключался напрямую, отключите прокси в настройках Telegram.

## Как это работает

Telegram подключается к прокси по адресу `127.0.0.1:1443` на том же телефоне. Ядро Flowseal открывает WebSocket-соединения к дата-центрам Telegram и использует резервные маршруты, когда это предусмотрено конфигурацией ядра. Приложение работает как локальный MTProto-прокси и обходится без системного VPN.

При первом запуске приложение генерирует 128-битный секрет для локального подключения. Он хранится в закрытых настройках приложения и передаётся Telegram в ссылке подключения. Статус **«Прокси запущен»** означает, что локальный порт открыт. Доступность дата-центров зависит от сети.

## Настройки

| Настройка | Что делает |
| --- | --- |
| Порт прокси | Меняет локальный порт. После смены снова откройте Telegram через приложение, чтобы добавить новый адрес подключения. |
| Маршрут загрузки файлов | Позволяет выбрать DC4, исходную схему DC2 + DC4 или режим без перенаправлений DC → IP. |
| Перезапуск при обрыве | Повторно запускает прокси после сбоя службы. |
| Тема и анимации | Позволяют выбрать тему и отключить анимации Utya. |
| Подробный журнал | Добавляет диагностические сообщения в журнал приложения. |

Порт и маршрут меняются при остановленном прокси. Настройки подробного журнала и перезапуска применяются при следующем запуске.

Если сообщения работают, а медиа скачиваются медленно, попробуйте **«Без перенаправлений»** в меню **«Маршрут загрузки файлов»**. Затем запустите прокси и повторите загрузку того же файла. Режим DC4 включён по умолчанию. [Рекомендации Flowseal по загрузке медиа](https://github.com/Flowseal/tg-ws-proxy#readme)

## Сборка из исходников

Понадобятся JDK 21, Android SDK 35 и Python 3.12 для Chaquopy. Откройте проект в Android Studio или задайте путь к Android SDK через `ANDROID_HOME` либо локальный файл `local.properties`.

**Windows**

```powershell
.\gradlew.bat assembleRelease
```

**Linux и macOS**

```sh
./gradlew assembleRelease
```

APK появится в `app/build/outputs/apk/release/app-release.apk`. Локальная сборка подписывается отладочным ключом вашего окружения. Для обновления установленного APK Android требует совпадения подписей.
