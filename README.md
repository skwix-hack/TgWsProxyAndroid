# TG WS Proxy для Android

Нативное Android-приложение by skwix. Kotlin, Jetpack Compose Material 3 и Python-ядро оригинального Flowseal/tg-ws-proxy через Chaquopy.

## Установка

Откройте APK на телефоне Android 8.0 или новее с 64-битным процессором ARM. Нажмите «Запустить прокси», затем «Открыть Telegram» и подтвердите добавление прокси в Telegram. Для остановки используйте большую кнопку приложения или действие в уведомлении. При остановке локального сервера отключите этот прокси в Telegram, если хотите вернуться к обычному подключению.

Статус «Прокси запущен» означает, что локальный сервер слушает порт. Доступность дата-центров и загрузку сообщений необходимо проверить на телефоне в своей сети.

## Настройки

Порт меняется при остановленном сервере. Тема и анимации применяются сразу. Подробный журнал и перезапуск после сбоя применяются при следующем запуске. Секрет создаётся случайно при первом открытии, хранится в закрытых настройках приложения и исключается из журнала. Автоматическое резервное копирование отключено.

## Сборка

Нужны JDK 21 и Android SDK 35. Укажите путь к SDK в локальном файле `local.properties` или задайте `ANDROID_HOME`.

```powershell
./gradlew.bat assembleRelease
```

На macOS и Linux используйте `./gradlew assembleRelease`. Готовый APK появится в `app/build/outputs/apk/release/app-release.apk`. Версия 0.2.0 собрана для ARM64. Локальная сборка использует отладочный ключ Android из окружения разработчика.

## Проверка

Локальная проверка жизненного цикла ядра проверяет запуск, открытие порта, остановку и повторный запуск. Проверка интерфейса и работы Telegram на Android-устройстве оставлена пользователю по его просьбе. В 0.2.0 обе анимации прозрачные, 30 кадров/с. Журнал собирается в UI только при открытой вкладке. Python запускается фоновым потоком службы.


## Маршруты медиа в 0.2.0

Новый маршрут по умолчанию — только DC4, как рекомендует README Flowseal при проблемах с загрузкой медиа. Настройки → Маршрут загрузки файлов позволяют выбрать DC4, отсутствие перенаправлений либо прежний DC2+DC4. Перед сменой остановите прокси. Эти режимы не измеряют и не гарантируют пропускную способность Wi-Fi, провайдера или Telegram. Параметр сохранится между запусками.

Проверено: сборка Release и Lint (0 ошибок), совпадение сертификата с 0.1.0, прозрачность ресурсов, все три конфигурации маршрутов, запуск/остановка/повторный запуск, обработка занятого порта и быстрое включение/выключение. На телефоне пользователя тесты не выполнялись, эмулятор не запускался по его просьбе.
